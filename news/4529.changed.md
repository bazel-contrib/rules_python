(rules) {obj}`pytest_test` uses `pytest-bazel` 1.0, which shards the tests
itself, so `pytest-shard` and `pytest-randomly` are no longer added to the
`deps` by default. `pytest_shard` is deprecated, and `pytest_randomly` is
optional: set it to run the tests in a random order. `pytest-bazel` 1.0 also
changes some defaults, e.g. `--test_filter` selects tests by their exact
names, see its [changelog](https://github.com/aignas/pytest-bazel/blob/main/CHANGELOG.md).
