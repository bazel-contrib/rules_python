(toolchains) Fetching a macOS python-build-standalone runtime from release
`20251209` or later no longer runs `install_name_tool`, because these releases
already set the `libpython*.dylib` id to `@rpath/<dylib>`. For older releases,
if `install_name_tool` is not on `PATH`, the id is left unchanged and a warning
is logged instead of failing the fetch
([#4527](https://github.com/bazel-contrib/rules_python/issues/4527)).
