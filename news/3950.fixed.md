(coverage) The warning about a missing bundled `coverage.py` wheel is now
emitted by `py_runtime` during analysis, for the runtime that toolchain
resolution selected and only when coverage is being collected. Previously it
was emitted once per registered platform lacking a wheel, on every build, which
warned about platforms a given build never uses
([#3950](https://github.com/bazel-contrib/rules_python/issues/3950)).
