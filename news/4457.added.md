(uv) Added the {obj}`vendor_uv_lock` macro, which vendors the needed subset of
a `uv.lock` file as a JSON string constant in a `.bzl` file, so that WORKSPACE
macros can use it. Its `.update` and `.run` targets first update the `uv.lock`
using the given {obj}`lock` target, so a single command updates both files,
and its `diff_test` checks that the vendored file is up to date without
network access.
