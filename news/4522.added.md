(pypi) {obj}`pip.configure` now adds the extras requested in the selected
`pyproject.toml` dependency groups, e.g. `requests[socks]`, to the hub, so
that the `@pypi//requests:[socks]` target exists and `@pypi//requests`
includes the extra even if the lock file does not request it. The environment
markers of the requirements are evaluated for each target platform, so an
extra is only added for the platforms that request it
([#2786](https://github.com/bazel-contrib/rules_python/issues/2786)).
