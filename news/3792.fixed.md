(binaries/tests) (Windows) `py_binary` and `py_test` no longer need the
privilege to create symlinks to run on Windows 10 1809, Windows Server 2019
or later. If creating a symlink fails, the venv that is created at runtime
uses hard links, junctions or copies instead
([#3792](https://github.com/bazel-contrib/rules_python/issues/3792)).
