(toolchains) With bzlmod, {attr}`python.toolchain.configure_coverage_tool`
uses the `coverage` package from the new `@rules_python_coverage` pip hub, which
locks the latest `coverage` version for each Python version starting from 3.9
and supports all of the platforms configured with {obj}`pip.default`. Passing a
`py_library` as the {attr}`py_runtime.coverage_tool` is now the preferred way,
and using a target without `PyInfo` will be deprecated in the next version
([#3902](https://github.com/bazel-contrib/rules_python/issues/3902)).
