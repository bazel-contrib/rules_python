(toolchains) With bzlmod, {attr}`python.toolchain.configure_coverage_tool`
uses the `coverage` package from a pip hub that is locked with a `uv.lock`
file in `rules_python`. It has the latest `coverage` version for each Python
version starting from 3.9 and the wheels for all of the platforms of the
toolchains. The package is added to the dependencies of the executables when
coverage is collected, like the {flag}`--coverage` flag target, instead of
being the {attr}`py_runtime.coverage_tool` of the toolchains
([#3902](https://github.com/bazel-contrib/rules_python/issues/3902)).
