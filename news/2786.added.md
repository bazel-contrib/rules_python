(pypi) The hub repositories now have a `[]` target for each package without
any extras and an `[extra]` target for each extra used in the lock file, e.g.
`@pypi//google_api_core:[grpc]`, in both bzlmod and `WORKSPACE`. The unified
`@pypi` hub of bzlmod has the same targets. The `requirement` macro accepts a
single extra, e.g. `requirement("google-api-core[grpc]")`. The
whl repositories also have the `[]` target and an `[extra]` target for every
extra that the package provides or the lock file requests, so they can be used
with a vendored `requirements.bzl`. In bzlmod the requested extras are no
longer passed to the whl repositories, so changing them does not refetch the
repositories. The members of
`experimental_requirement_cycles` can now be the extras of the packages, e.g.
`foo[bar]`. See
[the docs](https://rules-python.readthedocs.io/en/latest/pypi/use.html#extras)
([#2786](https://github.com/bazel-contrib/rules_python/issues/2786),
[#4168](https://github.com/bazel-contrib/rules_python/issues/4168)).
