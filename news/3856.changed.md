(pypi) Wheels downloaded with the Bazel downloader are now extracted once and
reused across Python versions and hub repositories in {obj}`pip.parse`. Wheels
with patches, annotations or {attr}`pip.parse.extra_hub_aliases` are still
extracted separately
([#2948](https://github.com/bazel-contrib/rules_python/issues/2948)).
This means that the files of such wheels are in a repository named
`whl_<name>_<version>_<tags>` instead of the repository that is named after
the hub and the Python version, which changes their runfiles paths.
