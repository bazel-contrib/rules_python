(coverage) Added the {flag}`--coverage` flag to use the `coverage` package
locked in the requirements, e.g. `@pypi//coverage`, without configuring the
Python toolchains. It can be a `py_library` that bundles plugins, and it can be
set per target via `config_settings`. A `coverage` package that a test already depends on is now
used instead of the toolchain coverage tool
([#3902](https://github.com/bazel-contrib/rules_python/issues/3902)).
